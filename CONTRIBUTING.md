# Contributing

Thanks for considering contributing to this starter project. A few quick guidelines:

- Open an issue to discuss larger changes or features before implementing them.
- Work on a branch named `feature/your-descriptive-name` and open a pull request against `main`.
- Keep changes focused and include tests or screenshots where helpful.
- Add or update documentation in README.md or create new docs under `docs/`.

Maintainers may update the contributing guidelines later; this is a lightweight starter.
